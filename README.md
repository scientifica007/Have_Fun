## Experiment 001 — ELSEWHERE / في مكان آخر

A pocket atlas of twelve impossible worlds. Travel, tune a signal receiver, recover surreal relics, collect postcards and export your expedition journal.

- Bilingual English / Arabic, responsive, offline-capable after downloading the HTML file.
- Procedural Canvas illustrations, no external dependencies, no audio, no accounts or remote storage.
- Progress is stored locally when browser storage is available.
- Everything in the atlas is fictional.

### Play

Download [`index.html`](index.html) and open it in a modern browser. To publish as a website, enable GitHub Pages from the `main` branch and `/ (root)` directory in repository settings. The expected address is https://scientifica007.github.io/Have_Fun/ (availability depends on Pages configuration).

This is a playground, not a research project. No grand purpose required.

## Experiment 002 — Wind Archipelago / أرخبيل الريح

A turn-based, procedurally generated nautical exploration and survival game in Arabic. Explore 15×15 fog-covered maps, manage fuel and hull integrity, trade salvage, upgrade your boat, and recover relics to unlock further archipelagos. Each seed is reproducible; the campaign has no preset final sector. Progress is saved locally, with JSON export. No network, audio, or external dependencies.

Play: [`archipelago.html`](archipelago.html) · [GitHub Pages URL (if enabled)](https://scientifica007.github.io/Have_Fun/archipelago.html).

Validation: 57 engine assertions passed before publishing, including 50 seeded map generations. Browser/UI testing is not yet performed.
